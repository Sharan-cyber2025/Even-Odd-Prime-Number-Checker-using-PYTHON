# Even/Odd & Prime Number Checker 

A Python program that checks whether a given number is even or odd and determines whether it is a prime number.

## Features
- Identifies even numbers.
- Identifies odd numbers.
- Checks whether a number is prime.
- Uses separate functions for each operation.

## Concepts Used
- User defined functions
- If else statements
- For loops
- Modulus operator (%)
- Return statements
- Mathematical operations

## Technologies
- Python 3

## How to Run
```bash
python3 even_odd_prime_checker.py
```

## Purpose
Developed to strengthen logical thinking and understand number-based operations using Python.
